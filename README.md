# Personal Portfolio Website

A simple and responsive personal portfolio website built using HTML5 and CSS3.

This project was created as a beginner-friendly portfolio project and demonstrates semantic HTML, internal navigation, forms, images, external links, and responsive design.

## 📁 Project Structure

```text
personal-portfolio/
│
├── index.html
├── README.md
│
└── images/
    └── profile.svg
```

## 🚀 Features

* HTML5 semantic structure
* Responsive design
* Header and navigation menu
* Home/Hero section
* About Me section
* Skills section
* Projects section
* Contact section
* Contact form with HTML validation
* Profile image with meaningful alt text
* Internal navigation links
* External GitHub and LinkedIn links
* Mobile-friendly layout
* No external frameworks or libraries required

## 🛠️ Technologies Used

* HTML5
* CSS3
* Git
* GitHub
* Visual Studio Code

## 📋 Sections

### Home

Introduces the portfolio owner and provides a button to navigate to the contact section.

### About

Contains personal information, interests, learning goals, and career objectives.

### Skills

Displays technical and professional skills using an HTML unordered list.

### Projects

Shows example projects and links to GitHub.

### Contact

Contains contact information and a contact form with built-in HTML validation.

## 📝 Customization

Before publishing the website, update the following information in `index.html`:

1. Replace `Your Name` with your actual name.
2. Replace `yourname@example.com` with your email address.
3. Replace the GitHub URL with your GitHub profile URL.
4. Replace the LinkedIn URL with your LinkedIn profile URL.
5. Update the About Me content.
6. Update the skills based on your actual skills.
7. Replace the sample projects with your own projects.
8. Replace `images/profile.svg` with your own profile picture if desired.

## 🖼️ Adding Your Own Profile Picture

You can add your own image to the `images` folder.

For example:

```text
images/
└── profile.jpg
```

Then change the image in `index.html`:

```html
<img
    src="images/profile.jpg"
    alt="Professional profile photo of Your Name"
>
```

Always use descriptive `alt` text for accessibility.

## 💻 How to Run Locally

### Option 1: Open directly

Double-click `index.html` to open it in your web browser.

### Option 2: Use Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Open the file in your browser.
4. If you have the Live Server extension installed, right-click `index.html`.
5. Select **Open with Live Server**.
